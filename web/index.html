처음 연결하기 · 업로드와 Qwiic 안내

① 전원을 끄고 SY-104 MPU6050의 SDA → P0.26, SCL → P0.27, VCC → 3.3V, GND → GND를 Qwiic으로 연결하세요.

② 이 새 게임의 arduino/NU40DK_Drone/NU40DK_Drone.ino를 Arduino IDE에서 열고 NU40-DK / USB 포트를 선택해 업로드하세요. 이전 다마고치 스케치에서는 기울기를 보내지 않으므로 새 스케치가 필요합니다.

지원 센서 외부 MPU6050(0x68/0x69)을 먼저 찾고, 없으면 NU40-DK 내장 LSM6DS3 계열(0x6A/0x6B)을 자동 탐색합니다. 별도 IMU 라이브러리는 필요하지 않습니다. 시리얼 로그에 실제 센서 종류와 주소가 표시됩니다.

③ 시리얼 모니터 115200bps에서 NU40-DRN-… 이름과 IMU:READY를 확인하세요. 센서가 없으면 5초마다 다시 찾습니다. 버튼은 INPUT_PULLUP / LOW, 디바운스 35ms이며 LED는 보드 패키지의 ledOn/ledOff를 사용합니다.

④ Chrome / Edge에서 보드 연결 → 보드 선택 → 평평하게 놓고 수평 보정 → 비행 시작. 1.2초 이상 움직이지 않고 유지해야 보정됩니다. 센서 장착 방향에 따라 90° 회전이나 방향 반전을 설정하세요.

USB 포트가 보이지 않을 때 충전 전용 케이블 대신 데이터 전송이 가능한 USB 케이블을 사용하고 PC에 직접 연결하세요. 그래도 포트가 없으면 RESET 버튼을 빠르게 두 번 눌러 업로드 모드로 진입한 뒤 새 COM 포트를 선택하세요. NRF52BOOT 드라이브가 나타날 수 있습니다. NUCODE 공식 안내

공개 데모는 별도 설치 없이 이 페이지에서 바로 실행됩니다. 보드가 없어도 ‘키보드로 체험’을 누르거나 터치 버튼으로 조종할 수 있어요.

소스를 내려받아 로컬에서 실행하려면 게임 폴더에서:

python3 -m http.server 3001 --bind 127.0.0.1 --directory web

주소: http://127.0.0.1:3001/. Windows에서는 python3 대신 py 또는 python도 가능합니다. 기록만 브라우저에 저장하며 서버 설치나 npm은 필요 없습니다.
